# phantom-blade-assets

Тайлы подложки и картинки окон меток для интерактивной карты [Phantom Blade Zero](https://broskiplay.ru/phantom-blade-zero-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/<карта>/<z>/<x>/<y>.avif` (512×512, z0–z5) и `tiles/<карта>/manifest.json` — список существующих тайлов
- Карты: `weeping-creek-valley` (Долина Плачущего ручья), `crimson-forest` (Багровый лес), `village-of-lu` (Деревня Лу),
  `pangzhen` (Панчжэнь), `the-mandates-encampment` (Лагерь Союза), `meigu-lake` (Озеро Мэйгу), `mountain-of-imprisonment` (Гора Заточения)
- `popups/<id>.webp` — картинки окон меток (640 px по ширине, WebP q80)

Тайлы взяты с [etalongame.com](https://etalongame.com/interactive-maps/phantom-blade-zero/map/weeping-creek-valley/) как есть (без перекодирования),
картинки меток — с [mapgenie.io](https://mapgenie.io/phantom-blade-zero/maps/weeping-creek-valley).
